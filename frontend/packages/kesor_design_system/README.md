# Kesor design system

The existing Customer App palette, type roles and Material theme, extracted without
visual changes for both Kesor apps. Original Figma references remain in source
comments. Both apps declare the bundled Poppins/Google Sans/Noto Sans Khmer fonts;
fonts remain app assets so existing family names and widget metrics stay stable.
The original Kesor mark is available as `assets/kesor-logo.svg` with package
`kesor_design_system`. Do not replace brand tokens independently in either app.
