# Settings artwork

Original SVGs exported from the user's Kesor Bank Figma frame `320:308`:
https://www.figma.com/design/Mkhqgqnt1SQoq4pn9INLY5/Kesor-Bank?node-id=320-308

User, chevron, lock, fingerprint, disabled toggle, bell, languages, sun/moon,
headset, file and logout artwork is bundled locally. Original 20/22/24px bounds
and the 44×26px off toggle are preserved. Theme tint supports dark mode.
No temporary Figma asset URL is used at runtime.
